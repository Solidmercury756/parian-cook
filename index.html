🐙 نصب دائمی روی GitHub Pages (بدون تبلیغ)

سرویس GitHub Pages کاملاً رایگان است، هیچ تبلیغاتی روی برنامه نمی‌اندازد و بدون فیلترشکن باز می‌شود. برای ساخت لینک دائمی در ۲ دقیقه:

گام ۱: دریافت کد یا فایل برنامه

گام ۲: رفع خطای 404 و ساخت صفحه در GitHub

  1. ابتدا دکمه «📋 کپی مستقیم کل کد» در بالا را بزنید.
  2. وارد مخزن (Repository) خود در گیت‌هاب شوید و روی Add file و سپس Create new file کلیک کنید (یا اگر قبلاً مستقیم وارد شدید روی creating a new file کلیک کنید).
  3. در کادر نام فایل (Name your file...) دقیقاً با حروف کوچک بنویسید: index.html
  4. در کادر بزرگ پایین صفحه، کد کپی‌شده را Paste (چسباندن) کنید و دکمه سبز Commit changes را بزنید.
  5. وارد تب Settings ⚙️ و بخش Pages شوید، زیر Branch گزینه main را انتخاب و Save کنید.
